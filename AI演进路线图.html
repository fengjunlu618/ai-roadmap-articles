01 / 摘要

AI 正在经历一场「三级跳」

真正的分水岭，不是模型更会聊天，而是它能不能替你把事情办完。沿这条线索，AI 的演进可以被清晰地拆成两个层次。

STEP 01

会说话的工具

对话范式：你问它答，AI 随叫随到，但任务的控制权始终在你手里。

STEP 02

能办事的系统

智能体范式：给定目标，AI 拆步骤、调工具、闭环交付，自己处理分支与重试。

STEP 03

在现实里学习、行动的伙伴

具身与自我进化范式：理解物理世界，动手行动，甚至改进下一代模型。

近十年，主线是交互范式的演进——AI 离「人」越来越近，从被调用走向被托付。

未来，主线是系统形态的演进——AI 离「世界」越来越近，从屏幕里的脑子走进现实。

02 / 主线一 · 交互范式

从「你问它答」到「替你办完」

这是过去十年大家体感最强的一条线。每一步，AI 都离「人」更近了一点：从被调用，到被托付。

01 1990s — 2010s
011990s — 2010s
按固定流程办事

规则与搜索时代

早期 AI 靠人工写规则，或从数据里找规律。代表有专家系统、搜索引擎、推荐算法。

特点是「按固定流程办事」——人在规则内寻找答案，AI 不越界。

02 2022 —
022022 —
你问它答

Chatbot 时代

ChatGPT 让大众体验到：用自然语言就能让 AI 写作、翻译、解答。使用门槛大幅降低。

但本质仍是「你问它答」——AI 是一面更聪明的镜子，响应你的每一次提问。

03 2021 — 2023
032021 — 2023
伴生辅助

Copilot

AI 进入你正在做的事里，补下一行代码、给一个建议。控制权始终在人手里。

它是你的搭档，不是你的代理人——你掌舵，它出力。

04 2023 —
042023 —
目标驱动

Agent

大模型有了规划、记忆与工具调用能力。你给一个目标，它能拆步骤、查资料、改文件、调软件，再根据结果自我调整。

编程领域常把这条线细分：Copilot 帮你补下一行代码；Coding Agent 理解整个项目，完成修改、测试与修复；Multi-Agent 让多个 Agent 分工协作，像一个小团队。

05 现在 —
05现在 —
绑定一个人

Personal Agent

Agent 进一步围绕「一个人」长期运行：记住偏好、目标与权限，跨应用持续推进任务，还能在后台持续工作。

Claude Duet、OpenAI Dots、Meta Muse 都属于这一方向。

关键一跃
Copilot → Agent

从「给你建议」
到「替你把事情办完」

整条路线里最关键的一跃，不是模型参数变大，而是责任转移：AI 从输出内容，变成交付结果。
顺带一提：Vibe Coding 与 Vibe Work 常被并列为「独立时代」，但它们更准确的定位是 Agent 的应用场景——以模糊意图、快速迭代、人机共创为特征的工作流，而不是与 Chatbot、Agent 同级的范式层级。

04 / 主线二 · 系统形态

往后的三步：基建、世界、自我进化

Personal Agent 只是入口。再往后，AI 会从「替你办事」，走向「长期懂你、跨应用办事、从结果里学习，最后进入现实世界」。

近期 · HORIZON 1
未来 1 — 3 年

Agent OS：给智能体一个操作系统

以后你不再一个个打开软件，而是给 AI 一个目标，由它调度邮件、日历、文档、财务、客服与代码。

关键不是模型更会聊天，而是这几样基建成熟。行业把它叫「驾驭工程」——给聪明的模型套上挽具，让它稳定干活。

长期记忆工具调用错误恢复多 Agent 协作权限控制
中期 · HORIZON 2
未来 3 — 7 年

世界模型 + 具身智能：走进物理世界

现在的 AI 还太像「屏幕里的脑子」。世界模型不只预测下一个词，而是预测「我这么做之后，世界会发生什么」。

再配上机器人、自动驾驶、自动化实验室，AI 就从数字员工变成能动手的主体——这就是 Physical AI / 具身智能。

世界模型机器人自动驾驶自动化实验室
远期 · HORIZON 3
5 年以上

Self-Improving AI：自我进化的研究机器

最猛的一步：AI 自己发现问题、设计实验、分析结果、改进下一代模型。

苗头已经出现——AI 写代码、调训练流程越来越常见。有预测认为，AI 可靠完成任务的时间约每 4 个月翻一倍，2026 年达到 16 小时级；但连续数周自主研究仍有距离。

自动科研闭环模型迭代长期自主

05 / 五个判断

把这条路线读清楚的五个关键

一

Vibe Coding 是应用场景，不是独立时代

它以模糊意图、快速迭代、人机共创为特征，本质是 Agent 的工作流。同一套 Agent 能力，既能做严谨的工单自动化，也能做 vibe 式自由创作。

二

Agent OS 是基建，不是模型

模型是引擎，Agent OS 是调度、权限、状态持久化与故障回滚的底盘。聪明的引擎，也需要一套可靠的底盘。

三

演进是叠加，不是替代

今天的 Agent 内部依然嵌套规则、校验与搜索，只是上层多了一层规划与自主决策。旧能力没有消失，而是被收编。

四

Self-Improving AI 不等于 AGI

自主改进可以是领域受限的：能自动优化代码与实验，不等于跨一切领域、拥有主观意识。别把「会自我进化」直接等同于「通用智能」。

五

AGI 会渐进落地，而非突变觉醒

它先在编程、科研、企业流程和机器人里一点点渗透，而不是某天突然「觉醒」。真正的分水岭，藏在每个可验证的交付里。

COMPLETE ROUTE · 完整路线
Chatbot→ Copilot→ Personal Agent→ Agent OS→ World Model / 具身智能→ Self-Improving AI

真正的通用人工智能（AGI）何时到来，目前仍无定论。
更靠谱的判断是：它会先在编程、科研、企业流程和机器人里一点点落地，
而不是某天突然「觉醒」。

时代的下一步，不是模型更聪明，而是系统更可靠。
